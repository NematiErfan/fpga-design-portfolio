# PWM Generator

## Overview

A VHDL-based Pulse Width Modulation (PWM) generator designed as a reusable digital hardware subsystem for FPGA applications.

The current implementation generates a 1 kHz PWM signal with a fixed 25% duty cycle, using a 50 MHz clock derived from a 100 MHz input clock through the MMCM_50MHz clocking IP. The design is verified through simulation using a dedicated testbench.

## Design Specifications

| Parameter | Value |
|---|---|
| RTL Language | VHDL |
| Input Clock | 50 MHz |
| PWM Frequency | 1 kHz |
| PWM Period | 1 ms |
| Duty Cycle | 25% |
| Output HIGH Time | 250 µs |
| Clock Cycles per Period | 50,000 |
| HIGH Cycles per Period | 12,500 |

## Architecture

The PWM output is generated by a counter that tracks clock cycles within each PWM period. The output is asserted during the configured HIGH interval and deasserted for the remainder of the period.

The current implementation uses a 50 MHz clock generated through the `MMCM_50MHz` clocking IP from a 100 MHz input clock.

## Repository Structure

- `rtl/` — VHDL RTL implementation
- `sim/` — Simulation testbench
- `ip/` — Clocking IP configuration (`MMCM_50MHz.xci`)

## Verification

The VHDL testbench checks the PWM output HIGH duration and period against the expected values of 250 µs and 1 ms, respectively. It also includes a basic reset-state assertion.

Simulation completed without assertion errors under the tested conditions. Verification coverage is limited to the implemented checks and does not represent exhaustive validation.

## Integration Notes

The RTL subsystem is intended to be reusable across FPGA projects. Board-specific pin assignments and timing constraints should be configured separately for the target FPGA platform.

The clocking IP configuration may require regeneration in the appropriate version of AMD Xilinx Vivado.
